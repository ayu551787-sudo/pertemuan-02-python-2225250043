## Daftar dan Fungsi Berkas

| Berkas | Fungsi |
| :--- | :--- |
| `latihan/01_biodata.py` | Menampilkan kartu biodata terformat dan mengukur perkiraan umur menggunakan `f-string`. |
| `latihan/02_persegi_panjang.py` | Menghitung luas dan keliling persegi panjang dengan format 2 angka desimal. |
| `latihan/03_konversi_suhu.py` | Mengonversi suhu dari Celsius ke Fahrenheit dan Kelvin. |
| `latihan/04_nilai_akhir.py` | Menghitung nilai akhir mahasiswa berdasarkan bobot Tugas (20%), UTS (30%), dan UAS (50%). |
| `tugas/kalkulator_koordinat.py` | Program utama untuk menghitung perubahan koordinat (dx, dy), jarak Euclidean, dan titik tengah antara dua koordinat. |
